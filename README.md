# Transport arrival in exclusion dynamics and quantum spin chains

Research code and validation data for the manuscript on receiver-dependent first-detection times in exclusion dynamics and quantum spin chains (Physica A submission).

Author: Mohamed Sacha · ORCID: https://orcid.org/0009-0005-2078-2032

## Reproducible XXZ benchmarks — 23 November 2026

- [Exact one-magnon XXZ](XXZ_Exact_One_Magnon/reproduce_xxz_sector.py): finite-ring exact diagonalization versus Fourier propagation, anisotropy independence in a polarized one-excitation sector, and Bessel/Airy first-crossing data.
- [Finite-temperature XX local reset](XXZ_FiniteT_Local_Reset/reproduce_xx_finiteT.py): local spin reset, single-site optimal discrimination in an open chain, four inverse temperatures, the free-fermion exact identity at Delta=0, a finite interacting comparison at Delta=1, and the boundary Airy front.

Both Python scripts exactly match the versions supplied with the 23 November 2026 submission archive (verified using Git blob hashes).

## Independent Q-SSEP checks

- [Block receiver likelihood](Q_SSEP_code/Block_receiver/verify_block_formula.py): direct SSEP generator compared against the receiver likelihood formula across five observation times and five receiver sets.
- [Plateau identity](Q_SSEP_code/Block_receiver/verify_plateau_identity.py): closed-form half-filling plateau and general-filling central-limit check.

## Reproduction

Required: Python 3, numpy, scipy, matplotlib.

Run:

    python XXZ_Exact_One_Magnon/reproduce_xxz_sector.py
    python XXZ_FiniteT_Local_Reset/reproduce_xx_finiteT.py
    python Q_SSEP_code/Block_receiver/verify_block_formula.py
    python Q_SSEP_code/Block_receiver/verify_plateau_identity.py

Each script writes its output beside itself (the one-magnon program also supports --outdir). Outputs include full validation CSV data, vector PDF figures, first-crossing CSV tables, and a JSON summary.

The first-crossing tables and validation summaries are also committed to this repository. The full validation tables and PDF figures can be regenerated by running the scripts. Additional Q-SSEP, TEBD, full XXZ ED and legacy diagnostic assets remain in the separate manuscript submission archive; this GitHub repository does not yet mirror every historical file.

## Interpretation

The one-magnon anisotropy independence is specific to the polarized single-excitation sector. Temperature independence of the local-reset signal is exact at the noninteracting XX point for the stated protocol, not a general finite-temperature result for interacting XXZ. The present datasets do not establish one universal interacting finite-temperature XXZ transport exponent.
