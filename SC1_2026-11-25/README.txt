This directory contains two independently executable finite-ring verification programs from the submission's SC1 archive, together with its pinned Python dependencies. The complete SC1 archive is provided with the manuscript, not mirrored in this directory. Its SHA-256 is:

faf8f2da6e10ed56a17838d6b383f88230b689862c393064de3395d08ead05b7  SC1_Code_and_Data.zip

Install the dependencies using python -m pip install -r requirements.txt. Run either Python script from XXZ_Thermal_General_Receiver; each creates a CSV output alongside itself. These calculations validate finite-ring identities and do not establish the thermodynamic hydrodynamic limit.
